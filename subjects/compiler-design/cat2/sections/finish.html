Q

Rapid drill · answer before revealing

If you hesitate on one, go back to that section immediately.

1. In CLR closure, what lookahead is assigned to B-items from [A→α·Bβ,a]?
FIRST(βa).
2. What exactly is merged in LALR?
CLR states with identical LR(0) cores; their lookahead sets are unioned.
3. Synthesized vs inherited attribute?
Synthesized comes from children upward. Inherited comes from parent/siblings; in L-attributed definitions it may depend only on parent/inherited info and left siblings.
4. What is an annotated parse tree?
A parse tree with the attribute values shown/evaluated at its nodes.
5. Why use a dependency graph?
To represent which attributes depend on which others and obtain a valid evaluation order via topological sort.
6. Quadruple vs triple?
Quadruple stores op,arg1,arg2,result. Triple omits explicit result names and refers to a computed temporary by its statement position.
7. Row-major address for zero-based A[i][j] with C columns and width w?
base + (i×C + j)×w.
8. Numerical vs flow-of-control Boolean translation?
Numerical computes 0/1-like Boolean temporaries. Flow-of-control uses jumps to true/false labels and supports short-circuiting.
9. Four backpatching primitives/ideas?
makelist, merge, backpatch, nextinstr/nextquad; plus truelist/falselist/nextlist attributes.
10. Three leader rules for basic blocks?
First statement; any jump target; any statement immediately following a conditional/unconditional jump.
11. Reaching definition vs available expression?
Reaching definition asks whether a definition can reach a point without being killed. Available expression requires the expression to have been evaluated on all reaching paths with no operand modified.
12. Live variable vs busy expression?
A live variable's current value will be used on some path before redefinition. A busy expression will be evaluated on some path before any operand is redefined.
13. Five peephole techniques in the source?
Redundant loads/stores, unreachable-code elimination, flow-of-control optimization, algebraic simplification/reduction in strength, machine idioms.

Final handwritten clue sheet

BCSE307L · Compiler Design CAT 2 · exact portion

CLR

LR(1) item [A→α·β,a]. Closure: from [A→α·Bβ,a], B-items get FIRST(βa). GOTO moves dot. Completed item reduces only on its lookahead. S′→S·,$ = accept.

LALR

Build CLR → merge states with same LR(0) core → union lookaheads → table. Source merges 3/6, 4/7, 8/9 in S→AA, A→aA|b.

SDD / attributes

SDD=CFG+attributes+semantic rules. Synthesized: children→parent. Inherited: parent/siblings→node. Annotated tree=tree+attribute values. Dependency edge c→b if b depends on c. Topological sort gives evaluation order.

L-attributed

For A→X1…Xn, inherited attr of Xj may depend on inherited attrs of A and attrs of X1…Xj-1 only. S-attributed uses synthesized only.

SDT

Semantic actions embedded in RHS; action position = execution order. Postfix pattern: E→E+T {print +}; T→T*F {print *}; F→num {print lexval}.

IR / TAC

Forms: syntax tree/DAG, postfix, TAC. TAC typical x=y op z. Reps: quadruple(op,a1,a2,result), triple(op,a1,a2), indirect triple(pointer list→triples).

TAC types

Binary, unary, copy, goto, conditional goto, param/call/return, indexed assignment, address/pointer assignment.

Arrays

1D: base+(i-low)w. 2D row-major: base+((i1-low1)n2+(i2-low2))w. Zero-based: base+(i*C+j)w.

Boolean

Numerical method computes Boolean temporary. Short-circuit method uses E.true/E.false jumps. not > and > or.

Backpatch

makelist(i), merge(p1,p2), backpatch(p,target), nextinstr. OR: patch left false to right start; merge true. AND: patch left true to right start; merge false. NOT swaps lists.

Optimization

Preserve semantics + improve speed/resources + reasonable compile time. Sources: CSE, dead code, code motion, copy propagation, strength reduction, constant folding, induction-variable elimination.

Data flow

Reaching def→propagation. Available expr→CSE. Live variable→register/dead code. Busy expr→code motion. out[S]=gen[S]∪(in[S]-kill[S]).

Basic blocks

Leaders: first statement; jump target; statement after jump. Block = leader up to before next leader. Flow-graph nodes=blocks, edges=possible control flow.

Block transforms

Structure preserving: CSE, dead code, rename temps, interchange independent adjacent statements. Algebraic: identities/cheaper equivalent ops.

Peephole

Small moving window over target code. Techniques: redundant load/store, unreachable code, flow-control simplification, algebraic simplification/strength reduction, machine idioms.
