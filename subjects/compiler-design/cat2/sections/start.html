Compiler-design survival map

For this subject, memorizing slides without seeing the transformations is a trap. Learn it as four mechanical systems.

A

Parsing states

CLR/LALR = grammar items moving through a state machine. Every table entry comes from an item and its lookahead.

B

Attribute flow

Module 3 = values/types flowing up, down or left across a parse tree according to semantic rules.

C

Lower the code

Module 4 = break high-level constructs into small machine-independent steps: TAC, labels, temporaries and lists.

D

Improve the code

Module 5 = detect repeated/useless/expensive work and transform it without changing meaning.
