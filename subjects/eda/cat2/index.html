C1 · Q2 — Visual non-stationarity + ADF

If both the mean rises over time and the variance of fluctuations grows, the series violates two stationarity properties and should be described as non-stationary.

ADF H₀: unit root ⇒ non-stationary · H₁: no unit root ⇒ stationary

Decision: p<0.05 → reject H₀ → evidence supports stationarity. A high p-value → fail to reject H₀ → keep the non-stationary diagnosis / transform or difference as appropriate.

C1 · Q4 — Spectral clustering end-to-end
  1. Standardize pH, Nitrogen, Moisture and Clay because the feature scales differ.
  2. Build an n×n affinity matrix, with the key using an RBF form: Aᵢⱼ=exp(−γ||xᵢ−xⱼ||²).
  3. Build the graph degree matrix D and the normalized Laplacian L=I−D⁻¹ᐟ²AD⁻¹ᐟ².
  4. Compute eigenvalues/eigenvectors.
  5. Sort eigenvalues ascending and use the eigengap: a large jump after λₖ suggests k clusters.
  6. Take the first k eigenvectors to form U (n×k); treat each row as the new representation.
  7. Run K-means on rows of U; map the resulting labels back to original samples.

The supplied worked key describes k≈2 for its five soil samples, grouping samples 1/3/5 versus 2/4 from their feature pattern. Treat that as the worked-key conclusion for that dataset, not a universal prediction rule.

Simpson’s paradox — complete exam explanation

Definition in the source: a trend/decision can differ when the same data are separated into groups versus aggregated. The textbook’s console-recommendation example shows that subgroup percentages can point one way while the combined percentage points another because the subgroup sample sizes differ greatly.

Answer structure: define paradox → show subgroup result → show aggregate result → identify unequal group sizes/confounding structure → state that whether to aggregate depends on the analytical question.

Correlation does not imply causation — complete explanation

The source distinguishes correlation (strength/direction of variables changing together) from causation (a change in one variable produces a change in another). It uses examples such as ice-cream sales and homicide to show that a third/background factor can drive both. The chapter explicitly recommends investigating hidden/confounding factors before drawing conclusions.

Statistics vs data analysis

The book frames statistics as methods for collecting, organizing, summarizing, presenting and analyzing data, plus drawing conclusions/decisions. It contrasts a model-first inductive process with a data-to-model deductive process and associates data analysis with the latter.

Variable classes

Continuous/quantitative: values across a continuum. Discrete/categorical: finite categories/codes. Chronological: quantitative or categorical observations attached to specified times.

Categorical subtypes

The book includes multiple forms, dummy variables made from quantitative intervals, logical 0/1 variables, and preference variables whose category codes have an ordering.

Statistical set

A set of observational units on which variables are measured. It distinguishes a whole population from a representative subset/sample.

Individuals–variables data set

Rows are individuals/units; columns are variables; a cell is the information/value of one variable on one individual.

Proximities data set

Instead of variable values, cells express a proximity/distance between pairs of individuals (or variables). This viewpoint connects naturally to Module 5 distance matrices.

1 · Mean, weighted mean, median, mode — full calculation

Arithmetic mean X̄

X̄ = Σxᵢ/n

Recipe: add every observation → count observations → divide.

Σx = 78+85+67+90+72+88+60+95+70+80 = 785
X̄ = 785/10 = 78.5

Check: Σ(xᵢ−X̄)=0, apart from rounding.

Weighted mean

X̄w = Σ(wᵢxᵢ) / Σwᵢ

Example: Internal=80 worth 40%, External=90 worth 60%:

(0.4×80 + 0.6×90)/(0.4+0.6)=32+54=86

Use weights/frequencies when observations do not contribute equally.

Median M

Recipe: sort. If n is odd, take position (n+1)/2. If n is even, average positions n/2 and n/2+1.

n=10 ⇒ middle positions 5 and 6 ⇒ (78+80)/2 = 79

The median minimizes the sum of absolute deviations and is robust to extremes.

Mode M₀

Recipe: make a frequency count; the value with greatest frequency is the mode. If every value occurs once, the set has no mode.

Here all 10 TotalMarks values are unique ⇒ no mode.

For a unimodal, mildly skewed distribution only: M₀ ≈ 3M − 2X̄
2 · Quartiles, quantiles, deciles, percentiles — including the course convention
Critical convention issueQuartiles are not unique across all software. The supplied CAT key uses the median-of-halves method on the 10 marks, because that gives Q1=70 and Q3=88. Use that method for a hand solution unless the question explicitly specifies a software/interpolation convention.

Course-key Q1, Q2, Q3

Sorted values:

60, 67, 70, 72, 78 | 80, 85, 88, 90, 95

Q2: full median = 79.
Q1: median of lower half = 70.
Q3: median of upper half = 88.

IQR = Q3−Q1 = 88−70 = 18

General quantile idea

Q1 is the 25th percentile, Q2 the 50th, Q3 the 75th. Deciles split the ordered data into 10 equal-frequency parts; percentiles into 100.

Manual exam rule: state the rank/interpolation convention if the requested percentile does not land exactly on an observation. Do not mix a calculator/software convention with the hand-solution convention halfway through.

Tiny Laplacian worked example · actually build A, D, L

For a simple unweighted chain 1—2—3, adjacency/affinity is:

A = [[0,1,0],[1,0,1],[0,1,0]]

Row sums are 1,2,1, so:

D=diag(1,2,1)
L=D−A=[[1,−1,0],[−1,2,−1],[0,−1,1]]

The eigenvalues are 0,1,3. The eigenvector for λ₂=1 is proportional to [1,0,−1]. Its signs illustrate the Fiedler split: node 1 on one side, node 3 on the other, node 2 at the boundary.

For Gaussian-mixture clustering, EM alternates soft memberships and parameter re-estimation:

E: rᵢk = πₖN(xᵢ|μₖ,σₖ²) / ΣⱼπⱼN(xᵢ|μⱼ,σⱼ²)
