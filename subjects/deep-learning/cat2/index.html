Module 3 · CNN foundations

Why CNNs exist: keep spatial structure, reuse local detectors, reduce parameter explosion.

Input idea

Images are grids

A grayscale image is a 2-D grid. An RGB image is a 3-D stack: height × width × channels. CNNs exploit that neighboring pixels are related.

Problem

Dense ANN is wasteful

Flattening a large image immediately into a dense layer destroys spatial locality and creates huge numbers of parameters.

CNN fix

Local connectivity + weight sharing

A small filter scans the image. The same weights are reused at every location, so one learned detector can look everywhere.

Convolution + pooling · make the dimensions obvious

These are the easiest marks to secure if you show the structure clearly.

Output size: O = ((N + 2P − F) / S) + 1
Remember: apply the formula separately to height and width. Number of filters = output depth.
Source-type examples: 32×32×3 with 5×5 filter and no padding gives 28×28 per filter. With 6 filters, output = 28×28×6. If you add padding 2, it stays 32×32×6.

Activation

Why activation matters

Without activation, several convolutions in a row collapse into a linear transformation. ReLU is the default modern intuition; tanh/sigmoid still appear in source explanations and older architectures.

Parameter counting · full source numerical

This is one of the explicit worked calculation patterns in the supplied Module 3 material.

Convolution parameters = (Fh × Fw × Cin + 1 bias) × number of filters
Fully connected parameters = Nin × Nout + Nout
Easy exam insight: convolution layers often look scary, but fully connected layers can dominate the parameter count. In this source problem, FC alone contributes 135,210 parameters.

Architecture evolution · one innovation per generation

Don't memorize five separate diagrams. Memorize what each architecture changed.

Exam memory

One-liner memory hooks

LeNet: early handwritten-digit CNN. AlexNet: ImageNet breakthrough with ReLU. VGG: many small 3×3 filters. GoogLeNet: Inception + 1×1 bottlenecks. ResNet: residual block y = F(x) + x.

High-yield comparison

What problem was solved?

VGG pursued simplicity via deeper stacks. GoogLeNet reduced computation while keeping power. ResNet targeted very deep training via skip connections.

Module 4 · RNN basics

An RNN is a network that carries state forward through time.

hₜ = activation(Wₓxₜ + Wₕhₜ₋₁ + b)
yₜ = Wᵧhₜ
Shared-weights intuition: the same Wₓ, Wₕ and Wᵧ are reused at each time step.

Module 5 · long-term dependency problem

This is the reason LSTM/GRU exist.

Vanishing gradient

Signal fades away

As gradients are repeatedly multiplied through long sequences, they can shrink so much that older information barely affects learning.

Exploding gradient

Signal blows up

Gradients can also become excessively large, causing unstable learning and wild updates.

Main fixes named in the material: gated units (LSTM / GRU), attention/self-attention, gradient clipping, explicit/external memory and other architecture/training improvements.

LSTM visual mechanics

See the cell state as a long memory conveyor belt with gates deciding what passes.

fₜ = σ(Wf xₜ + Uf hₜ₋₁ + b_f)
iₜ = σ(Wi xₜ + Ui hₜ₋₁ + b_i)
C̃ₜ = tanh(Wc xₜ + Uc hₜ₋₁ + b_c)
Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ
oₜ = σ(Wo xₜ + Uo hₜ₋₁ + b_o)
hₜ = oₜ ⊙ tanh(Cₜ)
Plain-English translation: forget gate keeps/discards old memory, input gate decides how much new information to write, output gate decides what part of updated memory becomes visible as hₜ.

GRU visual mechanics

GRU simplifies LSTM: fewer gates, no separate cell state.

zₜ = σ(Wz xₜ + Uz hₜ₋₁ + b_z)
rₜ = σ(Wr xₜ + Ur hₜ₋₁ + b_r)
h̃ₜ = tanh(Wh xₜ + Uh(rₜ ⊙ hₜ₋₁) + b_h)
hₜ = (1−zₜ) ⊙ hₜ₋₁ + zₜ ⊙ h̃ₜ
Fast comparison: LSTM has 3 gates + cell state Cₜ. GRU has 2 gates and no separate cell state, so it is usually presented as simpler/faster.

Optimization, ESN and explicit memory

The remaining Module 5 topics are easier once you see their purpose.

ESN

Echo State Network

Input enters a fixed random reservoir, which produces rich dynamics. Only the output weights are trained.

Gradient clipping

Control exploding gradients

Instead of letting gradient magnitude blow up, clip/rescale it to a manageable threshold so training stays stable.

Explicit memory

Separate memory store

Beyond hidden/cell state, the model can read from and write to an external memory-like structure for longer-context reasoning.

Deep Learning CAT 2 · Visual Clue Sheet

CNN output size

O = ((N + 2P − F) / S) + 1. Depth = number of filters. SAME tends to preserve size; VALID means no padding.

CNN parameters

Conv params = (Fh×Fw×Cin + 1)×Cout. FC params = Nin×Nout + Nout. Pooling/flatten add 0 trainable params.

Source big numerical

100×100×3 source network total = 139,820 params. Biggest contribution = FC layer: 135,210.

Architecture hooks

LeNet = early template. AlexNet = ReLU/ImageNet breakthrough. VGG = stacked 3×3. GoogLeNet = Inception + 1×1 bottleneck. ResNet = y=F(x)+x.

RNN equations

hₜ = activation(Wₓxₜ + Wₕhₜ₋₁ + b), yₜ = Wᵧhₜ. Source numerical: h₁=.858, h₂=.791, h₃=.785; y₃≈.864.

BPTT

Forward → loss → backward through time → update. Source final: Wx=.80862, Wh=.51517, Wo=1.01254.

Autoencoder / Seq2Seq

AE = encoder → bottleneck → decoder. Seq2Seq = input sequence → encoder → context → decoder → output sequence.

BERT

Input = token + position + segment embeddings. [CLS] for classification, [SEP] separator. MLM + NSP. Selected MLM tokens: 80% MASK, 10% random, 10% unchanged.

Long dependencies

Vanishing = gradients get too small. Exploding = gradients get too large. Solutions include LSTM/GRU, attention, clipping and memory mechanisms.

LSTM equations

fₜ, iₜ, C̃ₜ, Cₜ, oₜ, hₜ. Think: keep old memory → add selected new memory → expose selected output.

GRU equations

zₜ, rₜ, h̃ₜ, hₜ. No separate cell state. Reset gate filters old info; update gate blends old and candidate state.

ESN / clipping / memory

ESN: only output weights trained. Gradient clipping controls exploding magnitude. Explicit memory = separate readable/writable memory store.
